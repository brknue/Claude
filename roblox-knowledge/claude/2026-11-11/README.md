# Roblox game-making knowledge base (Claude, 2026-11-11)

Research on how Roblox games get popular, what players like, how games make money, and practical dev advice from YouTube creators and postmortems. Every number has a source link. Figures tagged `[3P]` (third-party trackers), `[self-reported]` (creator claims) or `[unverified]` should be treated with care.

**Start here:** [roblox-game-success-playbook.md](roblox-game-success-playbook.md) is the full synthesized report. It ends with an actionable playbook/checklist.

## Known limits
- YouTube coverage relied on transcript mirrors; most big tutorial channels were only reachable via titles/descriptions.
- Recommendation-signal weights are not public; per-game revenue is only tracker estimates.
- Snapshot as of 2026-11-11; Roblox changes payouts and discovery often, so re-check key rates before relying on them.
