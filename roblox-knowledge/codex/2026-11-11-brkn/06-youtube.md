# YouTube study guide
Access checked 2026-11-11. **No full video was watched or transcribed in this research.** The evidence below is limited to indexed YouTube descriptions/title metadata and the creator's written companion page. Technical implementation recommendations are cross-checked against official docs. Video titles can be renamed; publication dates may differ from a year shown in a title.

## V01: Studio and scripting entry point
[BrawlDev — Roblox Studio Basics, Beginners Scripting Tutorial #1](https://www.youtube.com/watch?v=9MUgLaF22Yo)
- Indexed YouTube description retrieved; publication metadata gives 2024-06-16 although the current title says 2025.
- Description introduces beginner, advanced and GUI paths and encourages following along/practice.
- Use for orientation, then [official tutorials](https://create.roblox.com/docs/tutorials).
- **Exercise, our recommendation:** build a button/door, explain every object reference, then change it to require two switches without copying a complete system.
- Not verified here: every episode's API correctness, completeness or teaching quality.

## V02: a concrete tower-defense slice
[GnomeCode — How to make a Tower Defense Game, #1 Path Navigation](https://www.youtube.com/watch?v=DanjB0cTfw0)
- Indexed description and chapter labels retrieved; publication metadata: 2021-12-14.
- Accessible chapters: setup at 0:13, moving the zombie at 2:04, creating waypoints at 3:49, moving between waypoints at 5:03.
- [Creator's companion/support page](https://gnomecode.com/tutorials/tower-defense) was also read. It describes a 22-episode series and corrections/common problems.
- **Exercise, our recommendation:** reproduce one lane with three waypoints, then test a slower enemy, widely spaced nodes and an anchored part.
- Version caution: older lesson code may use deprecated collision-group calls. Validate against [current collision docs](https://create.roblox.com/docs/workspace/collisions).
- This is an NPC movement lesson, not evidence of a secure/persistent production game.

## V03: official performance introduction
[Roblox Learn — How to use the MicroProfiler on Roblox](https://www.youtube.com/watch?v=XLCZfGEm9tU)
- Indexed YouTube description retrieved; publication metadata: 2024-09-25.
- Description introduces the profiler and links documentation/tag references. The video is embedded in the [official MicroProfiler docs](https://create.roblox.com/docs/performance-optimization/microprofiler).
- **Exercise, our recommendation:** capture a repeatable busy scene on a target device, inspect the expensive frame/task and compare a single change.
- Detailed profiling guidance in this knowledge base comes from the official written docs, not an unavailable video transcript.

## How to study a video safely — recommended
Write down the specific concept, expected hierarchy and client/server context. Build only that slice. Compare APIs with official docs. Test a failure and one independent variation. Save an explanation in your own words and a link to the original. Do not redistribute course files or long transcripts without appropriate permission.

## Next video research
Obtain legitimate, accessible captions or watch the actual content before expanding video-derived claims. Prioritize current security, data persistence, mobile UI, art import and publishing demonstrations. Record timestamps only after verifying them; do not invent a transcript from a title.
