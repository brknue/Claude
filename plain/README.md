# plain

The public list of every project in this repo: **https://brknue.github.io/Claude/**

Plain white (or black) page, "CRB" top left, search, list/grid view, light/dark mode, 20 built-in languages plus any other language through Google Translate (only when a visitor picks one). Clicking a project opens a panel with:

- **Open in browser** — the live project (GitHub Pages, or its own site)
- **Download all files (.zip)** — built in the browser from the files in the project folder
- **Download HTML** — the main HTML file
- **View on GitHub** — the project folder, where its README is shown
- **Copy link** — `https://brknue.github.io/Claude/#project-id` opens straight to that project

No cookies, no tracking, no third-party requests. Theme, view and language are kept in `localStorage`.

## Add a project

1. Put the project in its own folder at the repo root, with an `index.html` (and a `README.md`).
2. Open `plain/projects.js`, copy a block, paste it at the **top** of the list and fill in `id` (= folder name), `name`, `entry`, `open`, `tags`, `notes` and `desc` (English required; add the other 19 languages).
3. Run `node plain/build.mjs` — it checks the entry and refreshes `plain/files.js`.
4. Add a line to the root `README.md`, commit and push to `main`. GitHub Pages publishes it within a minute or two.

`open` rules: a relative path like `my-project/` is served by GitHub Pages from this repo; a full `https://` URL is for projects hosted elsewhere (for example Netlify); `null` shows "Not online yet".

## Files

| File | What it is |
| --- | --- |
| `../index.html` | the page (markup + styles) |
| `app.js` | list, search, views, theme, language, panel, downloads |
| `projects.js` | **the list of projects — the only file you edit to add one** |
| `i18n.js` | interface text in 20 languages + the Google Translate language list |
| `files.js` | generated by `build.mjs`: files and size of each project, used for zips |
| `zip.js` | tiny zip writer |
| `build.mjs` | checks `projects.js` and writes `files.js` |
