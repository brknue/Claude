# Lingua Local

Open `index.html` directly in a browser: no build, install, account or network is needed. The standalone HTML bundles 48 expressions in English, German, Turkish, Spanish, French and Italian. Interface and teaching notes are in English. This is a beginner foundation, not a complete fluency curriculum.

Features: learner profiles; known languages, levels and literacy; multiple learning targets; 15–60 minute plans; speaking-only or writing mode; self-assessed recall and spaced review; resumable lessons; local progress; JSON backup/restore; downloadable self-contained offline page; optional installed offline speech voices. No microphone, remote speech, analytics, CDN or API.

For hosted use, serve this directory on HTTPS. `sw.js` caches the page for subsequent offline visits. The downloaded HTML does not require a service worker. Device storage on file URLs depends on the browser: export backups regularly. Browser storage is not encrypted or shared between devices.

Scope: eight practical units, 48 expressions per language. No automated pronunciation scoring, certified placement, advanced curriculum or promise of fluency. Speaking feedback is self-assessment. A local voice is required for audio. Without it, text activities remain available.

Quality review results are in QA.md.
