## Changes
Converted transcribed TypeScript data to aligned JSON, added thematic groupings, retained available IPA, and made 26 everyday-language/semantic corrections. Where a term changed, the old IPA was removed to avoid mismatches. Full before/after changes appear in core-vocabulary.json. Imported unmodified data appears in upstream-swadesh.json.

Swadesh lists compare core concepts; they are not a CEFR-graded course. Multiple forms may reflect context, formality, gender or regional usage. This import is not a claim that every translation is universally interchangeable or independently validated by a language teacher.

## Other resources evaluated
- Tatoeba: https://tatoeba.org/en/downloads — useful for a future sentence corpus with per-sentence attribution; not imported in this update.
- Openjam: https://github.com/amirj4m/openjam — openly licensed, but its available translations did not cover the six required languages; not imported.
- Talhakasikci/cefr-vocabulary-dataset — not imported because source provenance and reuse terms were less clear for this purpose.

All included learning data is embedded in index.html. No runtime request to Wiktionary, GitHub, or any learning API is required.
