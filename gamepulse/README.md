# GamePulse

A small, plain game finder: featured games for console, PC, mobile and Roblox, a filterable catalog, and quick search links (RAWG, Steam, Wikipedia) for any other game.

- `index.html` — featured games and search
- `catalog.html?group=Roblox` — filterable list (`Console & PC`, `Mobile`, `Roblox`)
- `track.html?game=slug` — one game, with a "Save to my list" button (saved only in your browser)

No live data, no third-party scripts or fonts, works on phones, tablets and computers. To add a game, add an entry to `ITEMS` in all three pages.
